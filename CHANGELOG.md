# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 - 2026-06-07

- Added core CSV loading, grouping, validation, and CLI reporting.
- Added daily returns, mean daily return, cumulative return, annualized
  volatility, maximum drawdown, Sharpe ratio, and historical VaR.
- Added CAGR, Sortino ratio, Calmar ratio, configurable historical VaR
  confidence, and optional rolling volatility output.
- Added complete README, usage guide, metrics guide, contribution guide, tests,
  and CI workflow.
